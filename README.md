# Password Generator

This is a password generator, largely inspired from Hitesh Choudhary aka Chai aur Code, that helps you to generate password and copy them to your clipboard.

## Features

1. It can generate passwords of:
    - Variable Length (minimum of 8 characters and maximum of 15 characters)
    - Numbers (recommended for more secure passwords)
    - Characters (recommended for more secure passwords)
2. Copy the same to your device's clipboard

## Technologies Used

- React + Vite
- Tailwind CSS
